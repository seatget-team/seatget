# 첫 시연 범위

1. 사용자가 예매 회차와 좌석 상태를 확인합니다.
2. 좌석을 한 건 선점합니다. 같은 좌석에 동시에 들어온 요청 중 유효한 선점은 한 건만 남습니다.
3. 선점 유효 시간 안에 예약을 확정합니다. 만료된 선점은 확정이 거절되고 이후 요청이 좌석을 선점할 수 있습니다.
4. 같은 좌석에서 동시에 요청을 보내 비관적 잠금과 낙관적 버전 비교 또는 조건부 갱신을 같은 환경에서 비교합니다.

중복 예약은 0건이어야 합니다. 선점 만료와 확정이 충돌하는 경우 및 같은 확정 요청의 재전송도 별도로 검증합니다. 구현 비교에는 성공·충돌 건수, 처리량, p95 응답 시간, DB 잠금 대기와 실행 조건을 기록합니다.

결제, 대기열, 운영 배포는 후속 범위입니다.
