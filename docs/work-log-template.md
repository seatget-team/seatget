# 서비스 작업 기록 템플릿

새 Wiki 페이지 제목은 `YYYY-MM-DD 작업 제목`으로 적습니다. 아래 본문을 복사하고 각 항목을 작업에 맞게 채웁니다.

## 작업 목표

해결하려는 사용자 문제와 관련 이슈를 한두 문장으로 적습니다.

## 진행 내용

- 바꾼 예매 흐름, API, DB 또는 인프라를 적습니다.
- 변경을 확인할 수 있는 PR이나 커밋을 연결합니다.

## 결정 사항

- **결정** — 어떤 방식을 선택했는지 적습니다.
- **근거** — 선택 이유와 관련 ADR을 적습니다.

## 확인 결과

| 확인 항목 | 실행 방법과 조건 | 실제 결과 |
| --- | --- | --- |
| 검증할 시나리오 | 명령, 테스트 데이터, 동시 요청 조건 | 통과 여부, 측정값 또는 미실행 사유 |

좌석 상태나 트랜잭션을 바꿨다면 동일 좌석 동시 요청, 선점 만료와 확정의 충돌, 중복 확정 요청 중 변경에 해당하는 시나리오를 기록합니다.
